## Aclaración de nombres — 2026-11-23

Este repositorio se renombrará **Engine-Extensions-Matter**: adaptadores externos del núcleo Engine-Matter. El proyecto existente **Extensions-Matter**, sin el prefijo Engine, corresponde a módulos del bot y otras extensiones privadas (incluido Anti); no se renombra, no se fusiona ni se sobrescribe. El cambio de nombre en GitHub y el traslado de código ejecutable siguen pendientes.

## Decisión arquitectónica — 2026-11-23

Este repositorio **Telegram-Matter** está designado para convertirse en **Engine-Extensions-Matter** (con prefijo Engine), capa independiente de conectores de redes sociales externas para **Engine-Matter**. Su propósito deja de ser exclusivamente Telegram y abarcará WhatsApp, Telegram, Discord y futuras plataformas, siempre mediante contratos autorizados. El renombrado del repositorio en GitHub está **pendiente**. Hasta la migración y pruebas, no afirmar transportes funcionando ni desplegar adaptadores.

Ver [plan de migración](docs/ENGINE_EXTENSION_MIGRATION.md) y [estructura preparada](adapters/README.md). **Extensions-Matter** (sin prefijo Engine) es otro repositorio privado y no debe fusionarse ni sobrescribirse.
