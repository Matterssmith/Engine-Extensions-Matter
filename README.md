## Decisión arquitectónica — 2026-11-23

Este repositorio **Telegram-Matter** está designado para convertirse en **Extension-Matter** (singular), capa independiente de conectores de redes sociales externas para **Engine-Matter**. Su propósito deja de ser exclusivamente Telegram y abarcará WhatsApp, Telegram, Discord y futuras plataformas, siempre mediante contratos autorizados. El renombrado del repositorio en GitHub está **pendiente**. Hasta la migración y pruebas, no afirmar transportes funcionando ni desplegar adaptadores.

Ver [plan de migración](docs/ENGINE_EXTENSION_MIGRATION.md) y [estructura preparada](adapters/README.md). **Extensions-Matter** (plural) es otro repositorio privado y no debe fusionarse ni sobrescribirse.
