# Contrato Engine-Matter ↔ Engine-Extensions-Matter

Futuro contrato versionado y mínimo: eventos normalizados **sin confianza**, identidad autenticada del origen, autorización por actor/sesión/recurso/acción, aislamiento entre conectores, anti-replay, políticas de consentimiento y permiso expreso de envío. Las peticiones de comando no implican autoridad. El motor decide; el adaptador transporta. Vault custodia datos protegidos.

Estado: solo especificación, API/ABI por implementar y probar.
